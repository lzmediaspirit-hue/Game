Created with the built-in image generation tool. Runtime asset:
`art/environment/room-gate.png`. The original transparent PNG is preserved.
The renderer splits the shared texture into far/near portions for depth sorting;
no extra background, characters, NPCs or UI were generated.

## Generation prompt

Create a production game sprite: a single ornate wuxia / xianxia Chinese mountain pass ceremonial wooden paifang gate, isolated on a genuinely transparent background. Professional hand-pixelled 2D pixel art, crisp pixel edges with limited palette, jade teal curved tiled roof, aged red-brown wooden posts and muted gold carved trim, gray stone footings. No characters, no text, no glow portal, no scene background, no ground outside the footings. The gate is viewed from a three-quarter side angle for a side-scrolling 2.5D game: the open passage leads horizontally from LEFT to RIGHT, so the two posts recede in screen depth and their feet lie on a diagonal, rear post to upper-left and front post to lower-right. Tall open empty arch between posts, wide enough for the character, ornate upturned eaves. Overall sprite roughly 240 pixels wide and 300 pixels tall in a larger transparent square canvas, centered with empty margins, full structure fully visible. The far/rear post and nearest/front post must be easy to distinguish, so the game can sort the character between them. No extra props. Match richly textured but crisp classic wuxia pixel game scenery. Save the final PNG to the workspace if tool supports output files.
