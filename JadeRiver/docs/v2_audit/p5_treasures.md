# Audit · Packet 5: treasures, flying swords, talismans and gear upkeep (S47 + Part 8)

This audit compares the working tree after G2a (uncommitted) with `p5_treasures.md` (Jade River Build Prompt v2).
Nothing was run. The evidence comes from reading the code and the generated JSON.

**Baseline.**
- The build calls itself 1.1 (docs/CHANGELOG.md, "1.1 — The Azure Expanse"). Every spec milestone up to v1.1 is therefore nominally due, and v1.2 and later are future work.
- All G2a content lives in `data/items.json`. Treasures have `type: "treasure_art"` and a `treasure` dict. Vessels have `type: "vessel"` and a `flight` dict. Throwables have `type: "throwable"`, and the talisman has `type: "talisman"`. This content is generated by `tools/data/items.py:69-92,318-334`.
- There is no `treasures.json`, `talismans.json` or `salvage.json`.

Statuses:
- **Present:** exists and matches.
- **Differs:** exists, but with a different name, number or behaviour.
- **Partial:** part of it exists.
- **Missing:** nothing like it exists.

## 20. What G2a added that the spec does not ask for

These are not counted in the totals. Keep or drop each one deliberately.
- **Vessel speed.** `speed_mult` on each vessel: sword 1.25, cloud 0.95, gourd 1.1, leaf 1.0 (`items.py:85-92`). The vessel Qi multipliers are 0.8, 0.65, 0.85 and 0.75. Vessel sources:
  - the Flying Sword from `riding_the_wind` (CS1);
  - the Cloud Puff and Jade Gourd from the Mission Halls (CS1, 180 contribution);
  - the Maple Leaf from the Hermit (CS1, 600 taels).

  The spec gives no vessel numbers or sources.
- **Vessel intent.** `choose_vessel {item}` and the `vessel_changed` event (`inventory_authority.gd:483-489`). Vessels live in the key pouch, one copy kept.
- **Auto-fill.** The first treasure picked up fills Treasure 1 automatically (`inventory_authority.gd:191-194`).
- **Extra treasure effects.** Mirror reflections hit for 140 % Qi. The Gourd heals 1 % HP per absorbed missile. The Bell only Qi-seals bosses.
- **Throwable stats.**
  - Needles: three at 45 %.
  - Knives: 120 %, pierce 1.
  - Pellet: 160 %, burst 120, knockback 130.
- **Throwable shop listings:** Stoneford General (needles), Stoneford Smith (knives), port peddler (pellets).
- **Treasure shop listings:** Mission Halls (mirror and cauldron), Old Pan (pagoda), port peddler (gourd).
- **Extra events:** `treasure_set`, `beast_captured`, `talisman_struck`, `projectile_reflected`, `projectile_absorbed`, `projectile_burst` and `wisp_struck`, plus the new sfx `bell.wav`.
- **Projectile hit band.** It now reaches down to alt −56, so a shot at chest height hits small creatures (`combat_authority.gd:861`). This changes all player projectiles, not only throwables.
